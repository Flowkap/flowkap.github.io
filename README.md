## About

Personal site of Flowkap, served via GitHub Pages at <https://flowkap.dev/>.

Plain static HTML — no build step, no generator, no external requests:

- `index.html` – the single-page site (inline CSS/JS)
- `404.html` – not-found page
- `pixelme/` – standalone LEGO mosaic manual (not linked from the main page)
- `images/` – avatar and illustrations; web sizes are generated from the PNG originals

Open `index.html` locally in a browser to preview.
